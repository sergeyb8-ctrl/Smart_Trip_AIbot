# SmartTrip Bot

Планировщик поездок по Санкт-Петербургу на 1–5 дней.

Два равноправных входа:
- пошаговая анкета с кнопками — работает без ключей ИИ;
- свободное описание — Groq / GPT-OSS, при ошибке резервный Gemini.

Оба входа создают один TripRequest. Один Trip Engine фильтрует каталог, оценивает соответствие интересам, выбирает район и порядок посещений, проверяет оценочный бюджет, время и расстояния. LLM не придумывает места и не строит маршрут.

## Быстрый запуск на macOS

1. Остановите старую версию: Ctrl+C в её Терминале.
2. Распакуйте проект. Откройте Терминал в папке SmartTrip_MVP.
3. Выполните: bash run.command
4. При первом запуске создастся и откроется .env. Заполните BOT_TOKEN из BotFather.
5. GROQ_API_KEY и GEMINI_API_KEY добавьте при наличии. Без них доступна вся анкета и составление маршрутов.
6. Сохраните .env и повторите: bash run.command
7. В Telegram отправьте /start.

Нужен Python 3.10 или новее. При первом запуске устанавливаются зависимости в локальную .venv, поэтому нужен интернет.
Работать должна одна копия бота с вашим токеном. Для одновременной разработки каждый может создать отдельного тестового бота.
Локальный бот отвечает, пока программа работает и компьютер не спит.

## Команды

| Команда | Результат |
| --- | --- |
| /start, /menu | Главное меню |
| /trip | Пошаговая анкета без ИИ |
| /ai | Описание новой поездки или изменения последней |
| /history | Последние 5 поездок |
| /edit | Изменение параметров последней поездки |
| /delete | Удаление своей истории с подтверждением |
| /cancel | Отмена незавершённого действия |
| /help, /about | Помощь и границы сервиса |
| /myid | Telegram ID |
| /admin, /status | Закрытые команды двух администраторов |

В .env.example уже указаны ID 1136439707 и 1902707865.
Меню администратора не заменяет проверку прав: права проверяются в обработчике.
Каждый пользователь видит и удаляет только собственные поездки.
Выборы анкеты и история сохраняются в SQLite после перезапуска.
Обычная отмена не удаляет сохранённые маршруты.

## Как работает анкета

Город → 1–5 дней → общий бюджет → интересы → исключения → темп → начало дня → проверка → маршрут.
Интересы и исключения выбираются несколькими кнопками, затем «Готово».
Бюджет можно ввести числом, начало дня — временем ЧЧ:ММ.
На экране проверки любой параметр можно изменить.
После построения отображаются последовательность мест по дням, рекомендованное время, источники, расстояния и смета.
Для другого города сервис честно сообщает об ограничении, не заменяя его Петербургом.

## Бюджет и достоверность

Бюджет на одного человека включает посещения, питание и местный транспорт, но не дорогу до Петербурга и не проживание.
Резерв: 600 ₽ на питание и 200 ₽ на транспорт в день. Это учебные допущения, не персональный финансовый расчёт.
Цены билетов и длительность посещений также оценочные и хранятся в каталоге.
Алгоритм не превышает бюджет именно по этим оценкам. Реальные расходы могут отличаться.
Программа не бронирует билеты и рестораны.

В каталоге 60 реальных объектов OSM: 23 музея (включая 3 гастрономических), 17 парков и садов, 20 площадей и архитектурных объектов.
Места и координаты: © OpenStreetMap contributors, ODbL. См. DATA_LICENSE.md.
У каждого места есть ссылка на исходный объект, дата получения и примечание к цене.
Гастрономия в текущем каталоге — тематические музеи. Рекомендаций конкретных ресторанов пока нет.
Фильтры могут оставить недостаточно мест. Тогда сервис предлагает изменить условия вместо выдумывания объектов.

Пешие расстояния — расстояние по координатам × 1,3, а не путь по уличному графу.
Учитывается только ходьба между выбранными местами; дорога от жилья и обратно не включена.
Не проверяются мосты, перекрытия и входы; центр геометрии объекта может отличаться от входа.
Часы работы OSM сохранены как справочные строки, но календарные даты и расписания алгоритм пока не проверяет.
Предлагаемое время посещения рекомендательное: перед поездкой проверьте источники.

## ИИ

Основной провайдер — Groq, модель по умолчанию openai/gpt-oss-120b.
Резервный — Gemini, модель по умолчанию gemini-3.8-flash.
Модели задаются в .env и могут потребовать замены по мере изменения API.
Бесплатность, квоты и доступность зависят от аккаунта и региона; код не обходит ограничения сервисов.
Groq вызывается первым. При HTTP-ошибке, тайм-ауте, пустом или невалидном ответе вызывается Gemini.
Неизвестные параметры остаются null и уточняются теми же кнопками.
При недоступности обоих сервисов предлагается ручная анкета.
Для AI-разбора внешнему сервису передаются текст запроса и параметры только вашей последней поездки.
Проверьте распознанные параметры перед построением.

Запрос без Telegram-токена для отдельной разработки друга:
.venv/bin/python -m smarttrip.ai_cli "Петербург на 3 дня, бюджет 10000, архитектура, без музеев, спокойно после 10:00"

Это обращение к реальному AI API. Выполняйте со своими ключами.
Языковая модель не обучается с нуля; дообучение весов не реализовано.
Для самостоятельной настройки NLP см. docs/AI_HANDOFF.md.

## Проверка без Telegram и AI API

Установить тестовые зависимости:
.venv/bin/python -m pip install -r requirements-dev.txt

Запустить тесты:
.venv/bin/python -m pytest -q

Показать настоящий расчёт алгоритма без токенов:
.venv/bin/python -m smarttrip.demo --days 3 --budget 10000

Тесты используют подставные HTTP-ответы и Telegram-сессию; не отправляют сообщения и не тратят квоты.
Живые вызовы Groq/Gemini и запуск с вашим Telegram-токеном не проверялись авторами этой сборки: секретов в комплекте нет.

## Структура

smarttrip/telegram.py — aiogram, кнопки и анкета.
smarttrip/models.py — единый контракт и валидация.
smarttrip/ai.py — Groq/Gemini и промпт.
smarttrip/engine.py — рекомендации, бюджет и география.
smarttrip/database.py — каталог, история и состояние анкеты.
data/places_spb.json — 60 объектов с источниками.
tests/ — автоматические проверки.
docs/ — архитектура, распределение работы, требования и основа отчёта.

FastAPI не требуется для этой локальной версии. Интерфейс напрямую вызывает отдельные модули Python.
Его можно добавить позднее как дополнительный интерфейс к тому же ядру.

## GitHub и секреты

Репозиторий ещё не создан и код никуда не опубликован.
Инструкция публичной публикации: docs/GITHUB.md.
В архиве нет .env, реальных ключей, пользовательской базы, истории или .venv.
.gitignore исключает их из Git. Публикуется только .env.example с пустыми ключами.
Не помещайте секреты в код, скриншоты отчёта, тестовые примеры или сообщения бота.
Приложение не выводит ключи и тела запросов в логи.

История новой версии находится в runtime/smarttrip.sqlite3. Старая база предыдущего прототипа не переносится автоматически: она содержала свободные пожелания, а не рассчитанные маршруты.
Не удаляйте старую папку, если хотите сохранить те записи.
Перед переносом новой версии на другой компьютер остановите процесс и скопируйте .env и runtime отдельно от публичного репозитория.
