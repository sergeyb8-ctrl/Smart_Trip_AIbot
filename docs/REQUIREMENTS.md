# Требования и реализация

| Требование | Реализация | Проверка |
| --- | --- | --- |
| Python и aiogram | smarttrip/telegram.py, __main__.py | виртуальная Telegram-сессия |
| Анкета без AI | Form и общий TripRequest | полный ручной сценарий |
| Groq GPT-OSS, резерв Gemini | ai.py | HTTP-ответы, тайм-аут, 429, невалидный JSON |
| AI не строит маршрут | Draft → TripRequest → engine | одинаковый результат двух режимов |
| SQLite | places, trips, sessions | история, права, восстановление FSM |
| Петербург, 1–5 дней | модели и каталог | все длительности и темпы |
| 50–70 реальных мест | 60 элементов OSM с источниками | уникальность и данные каталога |
| Рекомендации и исключения | rank_places | жёсткая фильтрация и соответствие тегам |
| Контроль бюджета | резерв плюс оценочные посещения | итог не превышает заданный бюджет |
| Географическая оптимизация | плотный район, ближайшие подходящие места | тест изолированного объекта и лимита ходьбы |
| Перепланирование | /edit и AI с контекстом своей последней поездки | новая версия без потери предыдущей |
| История и удаление | /history, /delete с подтверждением | изоляция пользователей и отмена |
| Администраторы | два ID из .env | два разрешённых, отказ остальным |
| Секреты только .env | Settings.load, .gitignore | тест чтения .env и отсутствия ключей в repr |
| Публичный GitHub | исходники, CI и инструкция подготовлены | публикация ещё не выполнена |
| Документация для отчёта | docs/ | связка требований, кода и тестов |

Расписания, точный уличный граф и актуальные цены не относятся к подтверждённым возможностям этой сборки.
Готовность AI-адаптеров по контрактным тестам не подтверждает доступность и качество реальных провайдеров.
