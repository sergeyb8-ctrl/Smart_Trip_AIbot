# Публикация исходников на GitHub

Публичный удалённый репозиторий пока не создан.

1. Войдите в свой GitHub.
2. Откройте https://github.com/new
3. Назовите репозиторий smarttrip-bot, выберите Public.
4. При публикации существующего проекта не добавляйте автоматически README, .gitignore и лицензию: они уже есть.
5. Создайте репозиторий и сохраните его URL.

Если используется Терминал, GitHub показывает команды подключения существующего проекта.
В папке проекта выполните git init, затем git add . и git status.
Перед коммитом проверьте: .env, runtime, .venv и реальные ключи не должны быть в списке.
После этого создайте первый коммит и подключите URL, показанный GitHub.
Аутентификация выполняется вашим аккаунтом; не вставляйте токен GitHub в файлы проекта или переписку.
Для совместной работы добавьте друга через Settings → Collaborators.

В архив входят только исходники, пустой .env.example, каталог и документация.
.env и SQLite с пользовательскими поездками передаются на личные устройства отдельно и никогда не публикуются.
Если секрет уже попал в коммит, удаления файла недостаточно: ключ надо отозвать и заменить, затем очистить историю.
