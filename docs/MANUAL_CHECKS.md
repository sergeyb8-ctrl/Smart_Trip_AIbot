# Проверка на ваших устройствах

Это сценарии для живой проверки. Они не отмечены как выполненные.

1. Остановить старого бота, заполнить .env и запустить новую версию.
2. /start: видны два способа составления маршрута.
3. Без AI-ключей пройти анкету: Петербург, 3 дня, 10000 ₽, архитектура и парки, без музеев, умеренно, 10:00.
4. Проверить параметры, нажать «Построить маршрут». Ожидается 3 дня, реальные объекты с источниками и расходы не больше 10000 ₽ по оценочной модели.
5. Открыть историю и повторно показать маршрут.
6. Изменить бюджет через /edit; убедиться, что новый маршрут сохранён отдельно.
7. Прервать анкету, перезапустить программу и проверить продолжение с того же этапа.
8. С другого аккаунта убедиться, что чужая история не видна.
9. Обоим администраторам выполнить /admin; обычному пользователю — получить отказ.
10. /delete, затем «Отмена»: история сохранена. Повторить и подтвердить: удалена только своя история.
11. Добавить действующие AI-ключи и запросить ту же поездку текстом; проверить распознанные параметры.
12. Проверить запрос с отсутствующим бюджетом: бот должен спросить его кнопками.
13. Запросить Казань: бот не должен молча строить Петербург.
14. На тестовых ключах или при недоступном основном сервисе проверить Gemini; не публиковать ключи и HTTP-заголовки.
15. При недоступности обоих AI-сервисов пройти обычную анкету.
16. Проверить ссылки на реальные места, графики и цены перед реальным использованием маршрута.

Для отчёта сохраняйте дату, версию кода, сценарий, ожидаемый и фактический результат, скриншот без токенов.
Не выдавайте автоматический тест подставной сессии за эту живую проверку.
