# Проверка сборки

Дата: 19 октября 2026 года.
Среда: macOS, Python 3.12, aiogram 3.31.0, httpx 0.28.1, pydantic 2.13.5.

Команда: python -m pytest -q
Результат: 58 passed.
Проверка зависимостей: python -m pip check — No broken requirements found.

Проверены:
- все 1–5 дней и три темпа;
- отсутствие повторов, оценочный бюджет, время, лимит ходьбы;
- выбор плотного района вместо изолированного объекта;
- отказы при низком бюджете и недостатке мест;
- 60 уникальных объектов с источниками OSM;
- ручной диалог aiogram от /start до сохранённого маршрута;
- одинаковый результат ручного и AI-входа при одинаковых параметрах;
- изменение параметров, история, удаление и отмена;
- отсутствие доступа к чужой поездке по угаданному id;
- восстановление SQLite FSM после создания нового Dispatcher;
- просроченные кнопки;
- права двух администраторов и отказ другим;
- Groq → Gemini при 429, тайм-ауте, пустом и невалидном ответе;
- отсутствие сетевого обращения без ключей;
- null при недостаточных параметрах, чужой город не подменяется;
- загрузка секретов из .env и отсутствие ключей в repr.

HTTP и Telegram были подставными. Реальные платные/бесплатные AI API не вызывались, Telegram-токен пользователя не запрашивался.
Дообучение модели и точность реального NLP не измерялись.
Демо собственного алгоритма выполнено без сети; результат — docs/example_route.txt.
Цены не сверялись с актуальными билетными кассами.
Часы работы не используются как гарантированные расписания.
В момент этой проверки публичный GitHub и VPS ещё не были подготовлены. Размещение на удалённом сервере выполнено позднее, 25 октября 2026 года; этот протокол относится к базовой сборке.
