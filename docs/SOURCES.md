# Технические источники

Проверены при подготовке реализации 19 октября 2026 года.

- aiogram FSM: https://docs.aiogram.dev/en/latest/dispatcher/finite_state_machine/index.html
- aiogram Dispatcher: https://docs.aiogram.dev/en/dev-3.x/dispatcher/dispatcher.html
- Telegram Bot API: https://core.telegram.org/bots/api
- Groq strict structured outputs: https://console.groq.com/docs/structured-outputs
- Groq GPT-OSS 120B: https://console.groq.com/docs/model/openai/gpt-oss-120b
- Gemini structured output: https://ai.google.dev/gemini-api/docs/generate-content/structured-output
- OpenStreetMap attribution and licensing: https://www.openstreetmap.org/copyright

Конкретные места имеют отдельные ссылки в data/places_spb.json.
Стоимость и длительность посещений заданы авторами как учебные оценки, а не извлечены из этих технических источников.
Версии моделей и API могут меняться; значения моделей вынесены в .env.
