# Основа отчёта

Документ предназначен для дальнейшего заполнения фактическими результатами.

## Тема

Разработка интеллектуального планировщика путешествий с ручным и естественно-языковым вводом в Telegram.

## Цель

Разработать и проверить Telegram-сервис персонального планирования поездок по Санкт-Петербургу на 1–5 дней, в котором AI разбирает пожелания, а собственный алгоритм формирует маршрут с учётом интересов, оценочного бюджета и расположения объектов.

## Актуальность и практическая значимость

Планирование поездки требует сопоставлять места, интересы, расходы и время.
Два способа ввода позволяют пользоваться сервисом как без AI, так и через свободное описание.
Модульность позволяет отдельно исследовать понимание языка и качество построения маршрута.

## Объект и предмет

Объект: процесс персонального планирования туристической поездки.
Предмет: методы извлечения предпочтений, ранжирования мест и составления маршрута в Telegram-сервисе.

## Рекомендуемые разделы

1. Введение: проблема, цель, задачи, границы MVP.
2. Анализ требований: docs/REQUIREMENTS.md.
3. Архитектура и данные: docs/ARCHITECTURE.md, database.py, модели SQLite.
4. Интерфейс: скриншоты собственного запуска анкеты, AI-режима и истории.
5. AI: схема JSON, инструкции, резервирование, примеры ошибок и уточнений.
6. Trip Engine: формулы оценки, haversine, ограничения, псевдокод и пример.
7. Проверка: результаты pytest и отдельно реальные ручные/AI-проверки.
8. Разделение труда: фактические коммиты, задачи и вклад каждого.
9. Выводы: достигнутые функции, ограничения, дальнейшее развитие.
10. Приложения: GitHub URL, инструкция запуска, таблица источников каталога.

## Что подтверждено этой сборкой

Автоматические проверки ручного диалога, JSON-валидации, истории, прав, оценочного бюджета и географии; подставные ответы AI-провайдеров.
Конкретный итог проверки записан в docs/VALIDATION.md.

## Что пока нельзя писать как выполненное

Успешные живые вызовы API с вашими ключами, текущая точность NLP, дообучение нейросети, проверенные цены всех музеев, точный кратчайший путь, автоматический учёт календаря, публикация GitHub и развёртывание на VPS.
Для этих пунктов нужны отдельные действия и доказательства.
