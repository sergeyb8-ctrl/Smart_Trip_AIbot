# Каталог OpenStreetMap

data/places_spb.json содержит производный каталог OpenStreetMap.

© OpenStreetMap contributors. Данные распространяются по Open Database License (ODbL) 1.0.
https://www.openstreetmap.org/copyright
https://opendatacommons.org/licenses/odbl/1-0/

Получение: Overpass API, 19 октября 2026 года. Каждый объект имеет ссылку на исходный элемент OSM.
Для площадных объектов использован центр геометрии; это не гарантированная точка входа.
Названия, координаты и строка opening_hours происходят из OSM.
Стоимость и длительность — учебные оценки авторов. Они не являются актуальными сведениями о билетах.
Каталог из 60 мест выбран вручную из полученной выгрузки. Полная выгрузка и персональные данные пользователей не включены.
При распространении производной базы сохраняйте атрибуцию и требования ODbL.
